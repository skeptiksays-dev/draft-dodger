        Connect to Dota

        The helper is a small program that runs on your PC while you play. Dota sends it live game data through Valve's official Game State Integration, and the helper passes it to this site. It doesn't read game memory or change game files, so it's the same kind of thing stream overlays use.

        Easier option: the Draft Dodger desktop app has the helper built in, so there's nothing else to run.

        1. Download the helper and unzip it anywhere, for example your Documents folder.
          Download helper (Windows)
        2. Double-click Start-DraftDodger-Helper.bat. The first time, it adds the Game State Integration file to your Dota folder for you. If Windows asks whether to run it, choose Run.
        3. Add the launch option. In Steam: Library, right-click Dota 2, Properties, General, Launch Options. Add -gamestateintegration, then restart Dota.
        4. Turn on "Connect to Dota" on this page. Your browser may ask to let this site access apps on your device. Choose Allow, since that's how it reaches the helper.
        5. Start a game. The board fills in as heroes are picked. Keep the helper window open while you play, and don't click inside it (Windows pauses it). If it freezes, press Enter in it.
        How much fills in: Dota always tells the helper your own hero and team. Whether it also sends everyone's picks and bans to players (rather than only to spectators) isn't documented, so the status line here tells you after your first draft. Anything Dota doesn't send, you add by clicking as usual. A log file, gsi-log.jsonl, records what came through: it sits next to the helper, or in the desktop app use Open log folder.
        Works in Chrome, Edge and Firefox on Windows. To remove it later, delete the helper folder and gamestate_integration_draftdodger.cfg from dota 2 beta\game\dota\cfg\gamestate_integration.
